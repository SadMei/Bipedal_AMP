# MimicWM paper draft

This directory contains the anonymous, two-column LaTeX draft and bibliography.
The experiment section is intentionally left as a commented scaffold in
`main.tex`; no empirical result is claimed in the compiled paper.

Build with:

```bash
make
```

The output is `main.pdf`. Replace the generic article preamble with the exact
venue style file once a target CCF-A venue has been selected.
